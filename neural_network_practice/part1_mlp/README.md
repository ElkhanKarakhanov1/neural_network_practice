## Как работает прямой проход

Прямой проход превращает входной вектор признаков в предсказание сети.

Для каждого слоя выполняются две операции:

1. Линейное преобразование:

\[
z^{(l)} = a^{(l-1)} W^{(l)} + b^{(l)}
\]

где:

- \(a^{(l-1)}\) — выход предыдущего слоя;
- \(W^{(l)}\) — матрица весов текущего слоя;
- \(b^{(l)}\) — вектор смещений;
- \(z^{(l)}\) — взвешенная сумма входов.

2. Нелинейная активация:

\[
a^{(l)} = f(z^{(l)})
\]

В проекте доступны две функции активации:

- ReLU:

\[
f(z) = \max(0, z)
\]

- Сигмоида:

\[
f(z) = rac{1}{1 + e^{-z}}
\]

Для скрытых слоёв по умолчанию используется ReLU, так как она хорошо подходит для нелинейных зависимостей и обычно обучается быстрее сигмоиды. Сигмоида доступна как альтернативный вариант.

Выходной слой в текущей реализации является линейным:

\[
\hat{y} = z^{(L)}
\]

Это удобно для задач регрессии, где целевая переменная может принимать произвольные числовые значения.

## Функция ошибки

Для обучения используется среднеквадратичная ошибка:

\[
L = rac{1}{n} \sum_{i=1}^{n} (\hat{y}_i - y_i)^2
\]

где:

- \(n\) — количество примеров в батче;
- \(\hat{y}_i\) — предсказание сети;
- \(y_i\) — реальное значение.

Ошибка сохраняется после каждой эпохи в `loss_history`.

## Как работает обратный проход

Обратный проход нужен для того, чтобы понять, насколько нужно изменить каждый вес, чтобы уменьшить ошибку.

Для этого вычисляются частные производные функции ошибки по весам и смещениям:

\[
rac{\partial L}{\partial W^{(l)}}, \qquad
rac{\partial L}{\partial b^{(l)}}
\]

Процесс основан на правиле дифференцирования сложной функции — цепном правиле.

Для выходного слоя ошибка вычисляется как:

\[
\delta^{(L)} = rac{2}{n}(\hat{y} - y)
\]

Затем ошибка распространяется от последнего слоя к предыдущим:

\[
\delta^{(l)} = (\delta^{(l+1)} (W^{(l+1)})^T) \odot f'(z^{(l)})
\]

где:

- \(\odot\) — поэлементное умножение;
- \(f'(z^{(l)})\) — производная функции активации.

Для ReLU производная:

\[
f'(z) =
egin{cases}
1, & z > 0 \
0, & z \le 0
\end{cases}
\]

Для сигмоиды:

\[
f'(z) = f(z)(1 - f(z))
\]

Градиенты весов и смещений вычисляются так:

\[
rac{\partial L}{\partial W^{(l)}} = (a^{(l-1)})^T \delta^{(l)}
\]

\[
rac{\partial L}{\partial b^{(l)}} = \sum \delta^{(l)}
\]

## Градиентный спуск

После вычисления градиентов параметры обновляются в сторону уменьшения ошибки:

\[
W^{(l)} = W^{(l)} - \eta rac{\partial L}{\partial W^{(l)}}
\]

\[
b^{(l)} = b^{(l)} - \eta rac{\partial L}{\partial b^{(l)}}
\]

где \(\eta\) — скорость обучения.

Градиентный спуск выбран потому, что:

- он универсален и подходит для дифференцируемых нейронных сетей;
- он позволяет обучать модель итеративно, без необходимости аналитически находить оптимальные веса;
- он хорошо сочетается с обратным распространением ошибки;
- обучение по мини-батчам делает процесс более устойчивым и эффективным по памяти;
- при правильной скорости обучения ошибка обычно постепенно уменьшается.

В проекте используется стохастический градиентный спуск по мини-батчам: на каждом шаге обновление параметров выполняется по небольшой части обучающей выборки.

## Почему ООП целесообразно

Объектно-ориентированный подход здесь удобнее процедурного, потому что проект естественно описывается через объекты с состоянием и поведением.

### NeuralNetwork

`NeuralNetwork` хранит:

- размеры слоёв;
- матрицы весов;
- векторы смещений;
- выбранную функцию активации;
- историю ошибки.

Он также отвечает за:

- прямой проход;
- обратный проход;
- обучение;
- предсказание;
- сохранение и загрузку весов.

Без ООП пришлось бы передавать веса, размеры слоёв, функцию активации и историю обучения в каждую функцию. Это усложнило бы код и увеличило риск ошибок.

### DatasetManager

`DatasetManager` хранит:

- загруженные признаки и целевую переменную;
- названия столбцов;
- параметры нормализации;
- train/test выборки.

Он отвечает за:

- чтение CSV;
- нормализацию;
- разбиение данных;
- преобразование новых данных.

Такое разделение ответственности делает код понятнее: модель занимается обучением, а менеджер данных — подготовкой данных.

### Преимущества ООП

- Инкапсуляция: внутренние веса и параметры нормализации скрыты внутри объектов.
- Повторное использование: один объект `NeuralNetwork` можно обучать, сохранять, загружать и использовать для предсказаний.
- Читаемость: код отражает предметную область.
- Расширяемость: новые типы слоёв, активаций и методов оптимизации можно добавлять без переписывания всей программы.
- Обработка ошибок: собственные исключения делают понятным, какая именно проблема возникла.

## Наследование и композиция

### Наследование

Наследование полезно, когда новый класс является частным случаем существующего.

Например, можно создать базовый класс слоя:

```python
class Layer:
    def forward(self, x):
        raise NotImplementedError

    def backward(self, grad):
        raise NotImplementedError
```

Затем реализовать конкретные слои:

```python
class DenseLayer(Layer):
    pass


class Conv2DLayer(Layer):
    pass
```

Это позволит добавить сверточные слои, не меняя уже работающий код полносвязной сети.

Пример возможной иерархии:

```text
Layer
├── DenseLayer
├── Conv2DLayer
├── MaxPoolingLayer
└── DropoutLayer
```

### Композиция

Композиция полезна, когда сеть состоит из отдельных компонентов.

Вместо того чтобы хранить все веса в одном объекте `NeuralNetwork`, сеть может содержать список слоёв:

```python
class NeuralNetwork:
    def __init__(self, layers):
        self.layers = layers

    def forward(self, x):
        for layer in self.layers:
            x = layer.forward(x)
        return x
```

Тогда сеть можно собрать из разных слоёв:

```python
network = NeuralNetwork([
    DenseLayer(4, 8, activation="relu"),
    DenseLayer(8, 4, activation="relu"),
    DenseLayer(4, 1, activation=None),
])
```

Для добавления сверточного слоя достаточно создать новый класс и добавить его в список:

```python
network = NeuralNetwork([
    Conv2DLayer(...),
    MaxPoolingLayer(...),
    FlattenLayer(),
    DenseLayer(...),
    DenseLayer(...),
])
```

Таким образом:

- наследование позволяет создавать разные типы слоёв с общей структурой;
- композиция позволяет свободно собирать архитектуру из этих слоёв;
- это делает проект масштабируемым и приближает его к устройству современных библиотек глубокого обучения.
